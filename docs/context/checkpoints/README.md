# Checkpoints — Approved Decisions

This folder is the **decision log**, not a feature log. Every checkpoint must include: ID, date, status (`PROPOSED`/`APPROVED`/`REJECTED`/`SUPERSEDED`), decision owner, question/context, alternatives, decision, rationale, consequences, and affected documents.

Only the project owner can approve a checkpoint. AI agents may draft proposals but cannot self-approve. Keep prior decisions for history; supersede rather than silently rewrite.

`docs/update/` separately records what was actually implemented, tested, and changed.
